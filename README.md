# Microsoft 365 体験トレーニング

Microsoft 365 の主要サービスを、M365風の疑似UI上で操作しながら学ぶ研修用 Streamlit アプリです。

## 実行方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 内容

- Word: 白紙ページ編集、リボン操作、表挿入、コメント、保存・共有
- Excel: セル選択、数式バー、SUM計算、グラフ、シート保護
- Teams: @メンション、ファイル共有、リアクション、会議開始
- OneDrive: ファイル選択、ドラッグ＆ドロップ型アップロード、共有リンク、同期、復元
- SharePoint: サイト選択、ドキュメント追加、権限確認、ニュース投稿
- Copilot: プロンプト入力、要約、文章整理、次操作提案
